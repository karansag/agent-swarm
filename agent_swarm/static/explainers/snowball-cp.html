What a CP=2 experiment still needs

This is a plausible engineering route, not an already validated switch for the live OPD run.

Gate 01 · SkyRL

Enable packed samples

SkyRL currently rejects CP>1 unless sample packing is on. Shoveler’s live 32K OPD arm uses unpacked samples.

Gate 02 · Snowball

Choose all-gather locally

The model provider hardcodes all-to-all for sliding-window layers. Change those layers to KV all-gather, while keeping the global layers’ supported route.

Gate 03 · Validation

Check kernels and results

Test packed THD attention, sliding-window boundaries, gradients, and memory against CP=1. Then benchmark updates; all-gather sends more KV and may be slower.
